# Cold Source Game Files

This repository contains the runtime files and resource data required for the Cold Source game project.

## Project Content
*   **Game Logic**: Core scripts and behavior definitions.
*   **Resources**: Configuration files and game data.
*   **Assets**: Necessary files for the game engine to run properly.

## How to use
To use these files in your local development environment:

1. Clone the repository:
   ```bash
   git clone https://github.com/Cold-Source/Cold-Source-Game.git
   ```
2. Copy the contents to your engine's working directory or link the folders accordingly.
